## Course-level diffs (beyond Unit 1)

- 2e Starter = 12 units, each = Getting started + A + B + C + Unit Progress
  Test. Progression visible in scope & sequence: U1 be (I/you/we → he/she/they)
  → U2 it's/it isn't + possessives → U3 present simple I/you/we/they → U4
  present simple wh- questions + he/she/it → U5 there is/are → U6 present
  simple he/she/it negative+questions → U7 this/that/these/those + possessive's
  → U8-9 past simple → U10-12 (present continuous, can, future — per TOC).
- 1e had the same A/B/C + progress-test architecture. Verdict: **SAME** at
  course skeleton level.

## Conclusion

**Architecture continuity CONFIRMED.** Second Edition preserves: objective-
titled lessons, be fragmented across 1A/1B by person, countries→nationalities
vocabulary staging, 3-focus pronunciation per C lesson, workplace "first day"
narrative input, personal-profile writing with capitals/full-stops micro-skill,
and the self-check → Unit Progress Test → review close.

**Material changes (2e wins):** explicit CAN DO OBJECTIVES box; explicit
Listening/Reading/Speaking/Writing column per lesson; pronunciation
re-balanced into named per-lesson slots (syllables+word stress, main stress,
intonation); workbook-level Skills for Writing + Reading/listening extension +
Review blocks; this/these added to 1B.

**Unknowns:** 2e Unit 1 lesson-page internals (the sample unit is Unit 5);
exact exercise counts; Digital Workbook item mapping; whether the "first day
at work" video script differs from Sophia/Electric Blue.
